Expresiones regulares en JavaScript

Una expresión regular es un patrón que describe un conjunto de cadenas de texto. En JavaScript son objetos RegExp y se utilizan para buscar, validar o reemplazar texto. Son muy útiles para comprobar que la información que escribe el usuario en un formulario tenga el formato correcto antes de procesarla.

Formas de crearlas

Literal, entre barras (la más común):

const patron = /^[0-9]{4}$/;

Con el constructor, útil cuando el patrón se arma con texto:

const patron = new RegExp("^[0-9]{4}$");

Métodos más utilizados
  • patron.test(texto): devuelve true o false si el texto cumple el patrón.
  • texto.match(patron): devuelve las coincidencias encontradas.
  • texto.replace(patron, nuevo): reemplaza las coincidencias.
  • patron.exec(texto): devuelve la coincidencia y sus grupos.
Banderas (flags)
  • i: no distingue mayúsculas de minúsculas.
  • g: busca todas las coincidencias, no solo la primera.
  • m: ^ y $ trabajan por cada línea.
Símbolos básicos
Símbolo Significado
^ y $ Inicio y final del texto
\d Un dígito del 0 al 9
[A-Z] Un carácter dentro del rango indicado
{n} / {n,m} Exactamente n veces / entre n y m veces
+ / * / ? Una o más / cero o más / cero o una vez
\s Un espacio en blanco
( ) y | Agrupar y alternativa (uno u otro)
\. Un punto literal (se escapa con \)

Ficha del estudiante

Cada campo se valida mientras escribe. El patrón utilizado aparece debajo de cada campo.

Dos letras y tres números. Ejemplo: AB001
/^[A-Z]{2}\d{3}$/
Nombre y apellido, solo letras y espacios.
/^[A-Za-zÁÉÍÓÚÜÑáéíóúüñ]+(\s[A-Za-zÁÉÍÓÚÜÑáéíóúüñ]+)+$/
Formato ########-#. Ejemplo: 01234567-8
/^\d{8}-\d$/
Formato ####-######-###-#. Ejemplo: 0614-010190-101-1
/^\d{4}-\d{6}-\d{3}-\d$/
Use día/mes/año con una fecha real. Ejemplo: 25/08/2004
/^(0[1-9]|[12]\d|3[01])\/(0[1-9]|1[0-2])\/\d{4}$/
Ejemplo: estudiante@correo.com
/^[\w.+-]+@[\w-]+(\.[\w-]+)*\.[A-Za-z]{2,}$/
Solo números.
/^\d{1,3}$/

Datos obtenidos de la API Free-to-Play Games Database de RapidAPI con Fetch y async/await.

Clave de RapidAPI

Para consultar la API necesita su propia clave gratuita:

  1. Cree una cuenta en rapidapi.com.
  2. Busque Free-to-Play Games Database y suscríbase al plan Basic (gratis).
  3. Copie el valor de X-RapidAPI-Key que aparece en la pestaña de endpoints.

La clave solo se guarda en este navegador (LocalStorage) y no se sube al repositorio.
